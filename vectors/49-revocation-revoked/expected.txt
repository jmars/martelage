why it fails without the fix: MEASURED. The pre-fix verifier has no --revocation option
        at all, so this invocation ends at exit 2 "unknown option --revocation" — the
        input cannot be expressed, and revocation is reported unarmed on every run. With
        the option added and the CRL entry comparison removed (one line), this container
        reports exit 0 CONFORMANT with the revocation layer reading "checked CLEAN",
        while vector 34 still reports 0: the entry comparison is the only thing that
        turns this container from CONFORMANT to refused.
openssl: every one of these is run by the verifier on the supplied file — nothing is
        fetched, and no responder is contacted:
